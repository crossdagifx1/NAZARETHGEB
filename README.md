# Saint Gabriel Church website

Rebranded from the supplied Orthodox church template for Saint Gabriel Church in Adama, Ethiopia.

The site uses eight photos from the church's public Google Maps listing, includes a browsable gallery, and provides an Adama location/map, visitor guidance, parish information, and general annual feast references. The service-time, clergy, ministry, and news sections explicitly distinguish missing public information from confirmed parish details; template sample names, times, and announcements were removed. The prayer-request form was also removed because the static site cannot send requests to the parish.

Run `npm ci` and `npm run dev` for local development. `npm run build` creates the static site in `dist/` for publication.
