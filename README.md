# Saint Gabriel Church website

Rebranded from the supplied Orthodox church template for Saint Gabriel Church in Adama, Ethiopia.

The site offers English and Amharic modes through the language control in the header. It uses seven photos from the church's public Google Maps listing and omits the selected church-and-community photo from all placements. The browsable gallery, Adama location/map, visitor guidance, parish information, and general annual feast references remain available in both languages. The service-time, clergy, ministry, and news sections distinguish missing public information from confirmed parish details; template sample names, times, and announcements were removed.

Run `npm ci` and `npm run dev` for local development. `npm run build` creates the static site in `dist/` for publication.
